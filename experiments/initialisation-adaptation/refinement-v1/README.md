# Finer initialisation grid

This exploratory follow-up asks whether the scale-dependent pattern in the first
Tracking and Pong runs persists across a finer grid and more independent blocks.
It was designed after inspecting those results. It is not sealed confirmation.

The grid is 0.01, 0.02, 0.05, 0.1, 0.2, 0.5 and 1.0. Each task has four update
policies and ten independent paired blocks per scale: 280 trials per task, 560 total.
The primary contrast is weights-off minus both-on at each scale. Targets-off and
both-off are supporting controls. Retain all scales and policies in the report.

Tracking uses 200 nodes and ticks 1–2000; Pong uses 500 nodes and ticks 1–6000.
Both start without warm-up and retain the predecessor's task, body, initialiser and
sensory settings. The fresh root seed is 2026091801; the predecessor used 2026091701.
Pair topology and world streams across scales and policies within each task. Check
the realised seed ledgers for overlap before interpreting the results.

Validate without simulation:

```bash
julia --project=. bin/brainlesslab.jl check-experiment experiments/initialisation-adaptation/refinement-v1
```

Run one task branch at a time:

```bash
julia --project=. bin/brainlesslab.jl run-experiment experiments/initialisation-adaptation/refinement-v1 --branch tracking --root records/scale-refinement
julia --project=. bin/brainlesslab.jl run-experiment experiments/initialisation-adaptation/refinement-v1 --branch pong --root records/scale-refinement
```

Expect 280 trial rows and a completed operation record per branch. Verify checksums,
paired seeds, full scoring windows and ten independent blocks per condition. Report
raw `track_score` or `hit_rate`, normalised outcomes and clipping, paired differences
and pointwise uncertainty. Do not pool with the predecessor or call a selected best
cell confirmed. Ten blocks are a declared development budget, not a power calculation.

The bundle was generated by `../build_refinement.jl`, which performs no simulations.
Attach results to this branch in the programme, preserve the original study and append
dated discussion. Further refinement or confirmation requires a separately declared stage.
