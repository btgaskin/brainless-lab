# Test fixtures

Sealed reference data for the oracle test tier. Every file here is listed in
`SCIENTIFIC_FIXTURES.sha256` and verified by `test/test_fixture_integrity.jl`.
Tests never regenerate a missing or changed fixture.

## Provenance, and what these files are not

**No file in this directory is redistributed third-party material.** Every fixture is
output produced by code in this project or in its own predecessor implementations. This
matters for the `authors_*` files in particular, whose names describe what they are
*modelling*, not where they came from.

| Group | Produced by | What it establishes |
| --- | --- | --- |
| `authors_{wall,tracking,pong}.jld2` | `test/oracle/authors_falandays.jl` — a Julia transcription **in this repository** | Refactor regression: `src/nodes/Falandays.jl` still matches an independent transcription of the same equations, to 1e-9 |
| `falandays.npz`, `falandays_dale.npz`, `falandays_oosawa.npz`, `compartmental_*`, `ablation_*`, `env_*` | `test/oracle/*.py`, against the `crho` Python package in the sibling `v0.2` workspace | Cross-language agreement between the Julia implementation and a prior independent Python implementation, verified to 1e-9 |
| `single_agent_wall.npz` | same generator | **Construction input only.** Its `metric_*` ground truth is *not* verified — see below |
| `cma_sphere_trace.npz` | `test/oracle/gen_cma_trace.py`, using `pycma` | Injected-population parity for SepCMA mean and step-size updates, verified to 1e-12 |

### The `authors_*` files are not the authors' data

They are generated by `test/oracle/authors_falandays.jl`, a second Julia implementation
written in this repository against the same published equations. The upstream authors'
code was never executed to produce them, and none of their source, data, or figures is
copied or redistributed here.

That bounds what the corresponding test proves. `test/test_authors_parity.jl` is a
**refactor gate**, not evidence of fidelity to the publication: both sides of the
comparison were written by the same hand from the same reading, so a shared misreading
passes at 1e-9. The genuinely independent cross-implementation evidence is the `.npz`
group, which comes from a separate Python codebase.

### The wall fixture does not prove what its name suggests

**`single_agent_wall.npz`** supplies the reservoir masks, weights and parameters used to
build the replay, and that part works. But its `metric_score`, `metric_distance_window`,
`metric_collisions_window` and `metric_xy_path` ground-truth keys are **never compared to
anything**. `test/test_collective_single.jl` asserts shape, finiteness, and Julia-against-
Julia consistency only.

Enabling the comparison fails — with the environment initialised from the fixture's own
recorded `env_draws` and the reservoir fully pinned: `score` and `distance_window` each
deviate by exactly 1.0000000000000018 against a fixture value of 6.125, and `xy_path` by
4.116, against a 1e-9 tolerance. `collisions_window` "passes" only because both sides are
zero. Both implementations accumulate translation identically, so the definitions agree
and the values do not; an exact 1.0 points at a convention difference rather than drift.
The cause is unresolved, and the generator imports `crho` from a workspace outside this
repository, so it cannot be regenerated here to bisect. The assertions are `@test_skip`
with this reasoning recorded at the call site.

### SepCMA parity boundary

`cma_sphere_trace.npz` records ten `pycma` diagonal-CMA populations, their sphere
losses, and the mean and global step size after each update. The numerical test injects
those recorded populations into BrainlessLab's SepCMA core. This avoids treating NumPy
and Julia random-number streams as interchangeable. The recorded sphere losses, updated
means, and step sizes agree at `atol=1e-12, rtol=1e-12`. Candidate generation remains
covered by Julia-side determinism tests, not cross-language sample equality.

### Upstream reference

The model is published in:

> Falandays, J. Benjamin; Yoshimi, Jeffrey; Warren, William H.; Spivey, Michael J.
> "A potential mechanism for Gibsonian resonance: behavioral entrainment emerges from
> local homeostasis in an unsupervised reservoir network."
> *Cognitive Neurodynamics* **18**(4), 1811–1834 (2024).
> <https://doi.org/10.1007/s11571-023-09988-2>

The authors' own Julia source is public at
<https://github.com/bfalandays/ReservoirModel_followups>. It carries no licence file, so
it is cited and read, never vendored or redistributed. BrainlessLab's implementation is an
independent reimplementation of the published model; the constants it uses are recorded
with per-file provenance in `src/api/paper_config.jl`.

## Regeneration

The `.npz` generators import `crho` from a sibling `v0.2` workspace that is not part of
this repository, so **an outside contributor cannot currently regenerate them**. They are
archival: verify them, do not rebuild them. Regenerating a fixture to make a failing test
pass defeats the purpose of sealing it — if a fixture and the implementation disagree, the
implementation changed.

`authors_*.jld2` can be regenerated from this repository alone by running
`test/oracle/authors_falandays.jl`, but the same caution applies: the generator is the
other half of the comparison, so rebuilding it turns the test into a tautology.
