BrainlessLab's active implementation is Python 3.12 and Quadrants 1.3.3.
The package lives under `python/src/brainlesslab/`.
[Version history](/legacy/) locates the earlier source and its evidence boundary.

## Numerical and architecture boundaries

CPU64 uses strict ordered float64 arithmetic and is the reference policy.
Metal requires explicit float32 numerics and separate backend qualification.
CPU32 equation checks do not qualify Metal32.

The CI matrix requests CPU checks on Ubuntu 24.04 x64, Windows 2022 x64 and
macOS 14 arm64. These are configured architecture gates. Actual CI receipts establish
what passed; configuration alone does not qualify those platforms.
No CUDA, Vulkan, Linux arm64 or Windows arm64 qualification is claimed.

describe one macOS arm64 host with Python 3.12.13 and Quadrants 1.3.3. They are
bounded software checks, not qualification of every CPU architecture or study evidence.

These receipts retain their original tested source and counts. A changed release
needs fresh checks. Configured CI on another architecture remains pending until
its actual run passes.

```bash
uv sync --locked --group dev
uv run pytest
uv run ruff check python
uv run pyright
uv build
```

Keep first-call compilation, warm execution, host/device copies and recording costs
separate when profiling. Record backend, dtype, thread count and cache state.
Use the [performance guide](/python/performance/) to plan those measurements.

## Active scope

Falandays and SORN have separate equation and conformance boundaries.
Historical Falandays validation does not transfer automatically to Python.
SORN software checks do not establish authors-code trajectory parity or biological validity.

The active tasks include three physical control tasks, delayed cue and six additional
capacity-probe families. The library has 64 difficulty cells across delayed cue and
those six families. Availability is experimental software
readiness, not confirmed cognition or learning.

Dense model storage is the baseline. Batching and recording are bounded.
A sparse mask does not make the runtime a sparse implementation.

## Deliberate exclusions

General body composition, heterogeneous ecological populations, broad node registries,
evolution, general autodiff, durable checkpoint/resume and distributed execution are
not implemented in this release. Historical implementation capabilities remain available only
at their original source revision.

The website plays generated Quadrants development recordings. It has no TypeScript
neural or world equations, live parameter tuning or claim of learning from a selected case.

Accepted research records and historical benchmark tables retain their own provenance.
The rewrite neither reruns nor promotes them. Continue with
[implementation exercises](/python/learning/) and [research](/research/catalogue/).
