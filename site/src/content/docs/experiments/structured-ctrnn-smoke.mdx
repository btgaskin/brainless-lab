This checked example searches one fixed structured CTRNN on a development target. It then
evaluates the selected model on a held-out target with a separate root seed.

Its purpose is to validate the current `ExperimentSpec`, `EvolutionPlan`, checkpoint, and
record path. The one-generation budget does not support a claim about performance, search
reliability, or task generality.

Validate the bundle with:

```bash
julia --project=. bin/brainlesslab.jl check-experiment \
  experiments/examples/structured-ctrnn-smoke
```

The evidence state remains `planned`. No result is attached to this catalogue entry.
