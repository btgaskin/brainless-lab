## Make the neuron design an experimental object

BrainlessLab connects a node model, reservoir, body, task, world, and evaluation protocol.
The interactive demonstration places either Falandays or SORN in Pong, Tracking, or
CartPole Easy while keeping the surrounding task interface fixed.

The Falandays reference is validated on declared reference trajectories. SORN has a
separate software-conformance boundary. The browser demonstration is illustrative and
does not constitute benchmark evidence.

The four-task benchmark adds delayed-cue recall to Tracking, Pong, and Plank CartPole Easy.
Its v2 confirmation protocol is frozen and pending. Experimental CTRNN searches use one
shared design across all four tasks.

Use `simulate` for one diagnostic run. Use a typed operation plan when repeated work needs
exact settings, independent trials, and a portable record.

Every standard record preserves the submitted and resolved configurations, realised seed
streams, raw tables, summaries, provenance, and checksums. A record makes a run reviewable.
It does not make an exploratory result confirmed.
