## A small core with explicit research paths

BrainlessLab connects a node model, body, task, and evaluation protocol. The initial core
contains the fixture-validated Falandays implementation and two benchmark tasks: Tracking
and Pong.

Use `simulate` for one diagnostic run. Use a typed operation plan when repeated work needs
exact settings, independent trials, and a portable record.

Every standard record preserves the submitted and resolved configurations, realised seed
streams, raw tables, summaries, provenance, and checksums. A record makes a run reviewable.
It does not make an exploratory result confirmed.
