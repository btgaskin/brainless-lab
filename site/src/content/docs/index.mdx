## Make the neural design an experimental object

BrainlessLab connects a neural model, task, scientific protocol and execution policy.
Python constructs the system and analyses its records. Quadrants advances neural and
world state in bounded batches.

The display above plays curated Quadrants development recordings. Choose a recorded
case, pause, step, reset or inspect its provenance. The browser runs no neural or world
equations. A selected trajectory does not establish learning or benchmark confirmation.

The active models are Falandays and SORN. Tasks include Tracking, Pong, Plank CartPole
Easy, delayed cue and six additional experimental capacity-probe families.
The probe library retains 64 difficulty cells. Availability describes software, not
validated cognition or biological fidelity.

## Keep software and evidence separate

Task outcomes retain their key and native raw value. A frozen task calibration can also
provide a signed null-adjusted value. Different tasks remain different quantities.

Historical Julia Falandays validation covers declared reference trajectories at its
original implementation boundary. Python equations, backend qualification and observed
task performance need separate checks. Existing benchmark protocols and accepted records
retain their source revisions; this rewrite does not rerun or promote them.
