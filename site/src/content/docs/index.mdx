## Make the neuron design an experimental object

BrainlessLab connects a node model, reservoir, body, task, world, and evaluation protocol.
The interactive demonstration places either Falandays or SORN in Pong, Tracking, or
CartPole Easy while keeping the surrounding task interface fixed.

The Falandays reference is validated on declared reference trajectories. SORN and
CartPole remain experimental. The browser demonstration is illustrative and does not
constitute benchmark evidence.

Use `simulate` for one diagnostic run. Use a typed operation plan when repeated work needs
exact settings, independent trials, and a portable record.
