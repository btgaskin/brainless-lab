## What’s it like to be a neuron?

Start with the local view: inputs, activity and adjustment. Then ask what changes
when many simple units interact.

BrainlessLab gives this question an experimental form. Specify a neural reservoir,
place it in a declared task, and compare what happens. The opening visual introduces
the cellular perspective; it is not a BrainlessLab simulation or evidence about a
neuron’s experience.

## Make the neural design an experimental object

The active models are Falandays and SORN. Each has its own equations and local
adaptation rules. Tasks include Tracking, Pong, CartPole and delayed cue.
The capacity-probe library retains 64 difficulty cells across seven families.

Python constructs the system and analyses its records. Quadrants advances neural and
world state in bounded batches. You can change the design while keeping the task,
protocol and random streams explicit.

[Run your first simulation](/tutorials/first-simulation/) and inspect its task outcome.
Read the [system map](/handbook/system-map/) to see how the parts fit together.

## Keep the question and the record together

A plan declares the composition, protocol and scientific question. A portable record
preserves resolved settings, random-stream identities, individual outcomes and summaries.
Task outcomes retain their key, raw value and normalised value when a matching
calibration is available.

[Create a reproducible profile](/tutorials/reproducible-profile/) or
[compare conditions](/tutorials/compare-conditions/) with independent blocks and matched
worlds. Different tasks remain different quantities.

## Keep software and evidence separate

A completed run establishes execution. A task score does not establish cognition,
biological fidelity or general capability. Availability describes software, not
scientific confirmation.

Earlier Falandays validation covers declared reference trajectories at its
original implementation boundary; see [version history](/legacy/).
Python equation conformance, backend qualification
and observed task performance need separate checks. Accepted records retain their
source revisions and evidence status.
