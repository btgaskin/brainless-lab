The public package exports `NodeSpec`, `TaskSpec`, `CompositionSpec`,
`EvaluationSpec`, `EvaluationTarget`, `Plan`, `NumericalPolicy`, `ExecutionSpec`
and `TaskOutcome`.

Use `simulate` for one diagnostic and `task_outcome` for its declared outcome.
Use `resolve` and `execute` for a scientific plan.
Named operations are `profile`, `sweep`, `ablate`, `benchmark` and `calibrate`.
`decode` is an offline diagnostic over sparse emitted-activity observations.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
uv run brainlesslab run python/plans/delayed-cue.toml --root records
uv run brainlesslab inspect records/RECORD_ID
```

Check resolves without simulation. Run prints a new record path.
Inspect verifies the record for review; no command accepts study evidence automatically.

Read [plan format](/reference/plan-format/), [task catalogue](/reference/core-catalog/)
and [analysis](/reference/analysis/). The Python package lives under
`python/src/brainlesslab/`. Historical Julia API pages identify their source revision.
