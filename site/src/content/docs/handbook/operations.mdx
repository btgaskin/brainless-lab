The public operations are `profile`, `sweep`, `ablate`, `benchmark` and `calibrate`.
They use one `Plan` with named targets, a scientific protocol and evidence state.

A profile characterises one composition. A sweep compares explicit development cells.
An ablation changes a declared mechanism. A benchmark retains task-specific native
units and paired contrasts. Calibration freezes a task-matched null policy.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
uv run brainlesslab run python/plans/delayed-cue.toml --root records
```

Inspect the new record printed by the command. A successful run preserves its protocol,
random identities and outputs; it does not confirm a hypothesis.
Use `decode` offline for sparse probe diagnostics.

Evolution, general checkpoint/resume, autodiff and distributed operation execution
are not implemented in this release. Historical Julia operations remain at their
original source revision.
