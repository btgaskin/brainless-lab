---
title: Extending BrainlessLab
description: Choose the smallest supported change and preserve its conformance boundary.
---

Prefer model parameters or task options before adding a new substrate.
Construction, runtime dynamics and offline analysis must remain separate.

```bash
uv sync --locked --group dev
uv run pytest python/tests/test_sorn.py
```

Read a focused model suite alongside its kernels. A new equation needs an independent
reference calculation, reset/freeze tests, finite-state reporting and batch independence.
Keep array ranks fixed, use runtime dimensions and own returned snapshots.

Public scientific values are immutable. Execution policy owns placement and memory;
it must not silently change trial randomness or scoring.
Labels are diagnostic metadata, rather than controller inputs.

General registries, arbitrary bodies, evolution and autodiff remain unsupported.
Historical Julia extensions use their original interface at d0fc756d.

Continue with [the extension tutorial](/tutorials/extend-project/) and
[implementation exercises](/python/learning/).
