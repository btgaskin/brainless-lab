---
title: Task ports and interaction
description: Use the declared task interface without assuming a general body system.
---

Each active task declares neural input and effector widths, world-state rules and
action cadence. Check these values before tick zero.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

The resolved protocol should expose compatible model and task ports.
Neural and world state advance in Quadrants; host construction and recording do not
define extra neural dynamics.

A generic body/geometry/physiology composition system and heterogeneous ecological
populations are historical Julia capabilities, rather than active Python interfaces.
Read their original source at [d0fc756d](https://github.com/btgaskin/brainless-lab/tree/d0fc756d).

Use [the active task catalogue](/reference/core-catalog/) and
[platform limits](/platform-limits/) to choose a supported composition.
