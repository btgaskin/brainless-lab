A task defines observations, action timing, world updates and a native outcome.
A trial executes that opportunity in one seeded world. A batch groups compatible
trials for execution; it does not create a shared ecological population.

The material from this page now lives with the relevant guides.

## Discover a task before assembling it

[Choose a task](/benchmarks/tasks/) covers all ten families and includes a contract
inspection example. [Task contracts](/reference/core-catalog/) lists port widths,
cadences, horizons and outcomes.

## Interpret a world and a trial

[Trials, blocks and random streams](/handbook/evaluation/) explains construction,
full resets, episode termination and independent units. Reversal rounds belong to
one continuous trial.

## Interpret a batch

The [system map](/handbook/system-map/#keep-batches-separate-from-scientific-identities)
explains admission and stable identities. Use [speed and memory](/python/performance/)
for execution measurements. More slots do not add independent repetitions.

General body composition and mixed ecological populations remain
[historical capabilities](/experimental/).
