---
title: Worlds, tasks and batches
description: Distinguish stable scientific identities from physical execution slots.
---

A task owns its inputs, actions, world update and native outcome.
A trial executes one declared composition in one independently seeded world.
A batch groups compatible work for execution; it does not add scientific replicates.

The active tasks are Tracking, Pong, Plank CartPole Easy, delayed cue, recall
interference, delayed XOR, evidence accumulation, context integration, temporal order
and reversal adaptation. The capacity-probe library has 64 declared difficulty cells.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

Check compatible ports and a valid task horizon in the resolved output.
Stable condition/block/trial/entity identities own random streams.
Physical slots may change with batch size without changing those identities.
Inactive slots must not advance dynamic or random state.

Use independent blocks or trials for inference. A larger batch is an execution choice,
rather than a larger scientific sample. General body composition and mixed populations
remain outside this release.
