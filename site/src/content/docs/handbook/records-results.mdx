---
title: Records and results
description: Inspect native outcomes and provenance before interpreting a run.
---

A record makes an executed protocol inspectable. It retains requested and resolved
settings, random identities, raw trial outcomes, summaries and checksums.

```bash
uv run brainlesslab inspect records/RECORD_ID
```

Use the path printed by `run`. Check the task, node, horizon, warm-up, reset,
construction scope, numerical policy and seed partition before comparing records.

Report the outcome key, raw value, scoring window and calibration status together.
A missing calibration leaves the adjusted value unavailable. A valid null adjustment
may be negative; retain that sign.

Intervals use independent model blocks. Empirical null calibration retains its own
1,024 independent trajectories and uncertainty. Keep raw and null intervals separate
from the adjusted ratio interval. Invalid denominator draws make that interval unavailable.

Historical accepted records keep their original schema, source revision and evidence
state. A maintainer replay is a linked reproduction check, not another independent sample.
Only a human maintainer accepts a research contribution.
