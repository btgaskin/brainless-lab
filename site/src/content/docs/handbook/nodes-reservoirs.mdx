title: Nodes and reservoirs
description: Keep neural equations, construction and adaptation explicit.
---

A node defines a local neural rule. A reservoir is the runtime population coupled to
declared task inputs and effectors. Count belongs to `CompositionSpec`, rather than
to model coordinates.

The active models are Falandays and SORN. Both construct owned arrays on the host and
advance in Quadrants. Matrices use destination/source orientation. Dense storage is
the baseline; no sparse performance claim follows from a sparse construction mask.

Falandays has a historical Julia validation boundary on declared reference trajectories.
Python equation tests and backend qualification are separate gates.

SORN uses synchronous binary excitatory/inhibitory threshold dynamics, E-to-E STDP,
incoming-row normalisation and intrinsic threshold adaptation. Its historical
`inhibitory_fraction` name denotes an I/E ratio. Pruned edges cannot regrow.
This software boundary does not establish authors-code trajectory parity or criticality.

```bash
uv run pytest python/tests/test_sorn.py
uv run pytest python/tests/test_falandays.py
```

These checks test their declared implementation boundaries.
Keep `freeze_weights` separate from `freeze_plasticity`; reset restores initial
weights, masks, dynamic state and plasticity flags.
