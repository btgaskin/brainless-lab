---
title: Plan file format
description: Use the checked example and one scientific schema.
---

A `Plan` contains an ID, named targets, an `EvaluationSpec`, a `NumericalPolicy`,
operation, question, version and evidence state. Targets retain composition and stable
pairing, construction and mechanism identities.

The maintained syntax example is `python/plans/delayed-cue.toml`.
Use its real field structure rather than copying a historical Julia operation plan:

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

Successful resolution should expose compatible ports, declared horizons and random
stream policy without simulation. Invalid configurations fail before execution.

Placement, batch size, memory and recording belong to `ExecutionSpec`.
Do not create a new plan schema for each operation.
A development plan cannot confer confirmed or promoted evidence.
