---
title: Interfaces
description: Keep scientific values and owned runtime storage separate.
---

Scientific specifications are immutable Python values.
The public layers are `NodeSpec`, `TaskSpec`, `CompositionSpec`,
`EvaluationSpec`, `EvaluationTarget`, `Plan` and `NumericalPolicy`.
`ExecutionSpec` controls placement and bounded resource use.

Model construction returns owned NumPy arrays.
A model batch owns Quadrants ndarrays. Frozen typed bundles expose fixed ranks;
batch and node dimensions remain runtime values. Matrices use destination/source
orientation. Ordered destination-owned sums avoid floating-point atomics.

A step receives declared inputs, noise and an active-slot mask.
Inactive slots must not advance state. Reset restores initial weights, masks,
thresholds/targets, dynamic state and plasticity flags.
Snapshots own their host storage.
