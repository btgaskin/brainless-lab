The active Python task names are:

| Task | Question |
| --- | --- |
| `tracking` | Can a controller follow the moving stimulus? |
| `pong` | Can the paddle intercept the ball? |
| `cartpole_plank_easy` | How long does the declared controller balance the pole? |
| `delayed_cue` | Can it choose the earlier binary cue after a delay? |
| `recall_interference` | What survives intervening distractors? |
| `delayed_xor` | Can the delayed binary relation affect the response? |
| `evidence_accumulation` | Can distributed evidence affect the response? |
| `context_integration` | Can context select the relevant response rule? |
| `temporal_order` | Can the order of observations affect the response? |
| `reversal_adaptation` | Can responses track a changed reward contingency? |

The six additional capacity-probe families retain 64 declared difficulty cells.
They are experimental software, rather than validated cognitive constructs.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

Respect each task's scored horizon, action cadence and port interface.
Use `task_outcome` to read its key and raw value.
Upper bounds are task opportunity bounds, not implemented oracle demonstrations.

Normalised values remain task-specific. Do not form a cross-task competence score.
Continue with [calibration](/reference/analysis/) and [platform limits](/platform-limits/).
