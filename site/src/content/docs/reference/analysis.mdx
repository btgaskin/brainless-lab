---
title: Analysis and calibration
description: Keep task adjustment and offline decoding independent of the controller.
---

Raw outcomes retain native task units. A frozen task-matched calibration adds:

```text
null_adjusted = (raw - null_mean) / (upper_bound - null_mean)
```

Negative values remain visible. An unavailable or non-positive denominator leaves
the adjustment unavailable. Tracking and Pong have bound 1, CartPole has its declared
step bound up to 15,000, and binary probes have bound 1. These bounds are not implemented
oracles. Analytic binary chance is 0.5 where declared.

Empirical calibration freezes 1,024 independent null trajectory scores.
Its signature includes task options, initialisation, scored horizon, warm-up, action
cadence, numerical/RNG policy and world-source hashes. It excludes reservoir count,
kind, topology and input gain.

Adjusted intervals independently resample model blocks and calibration trajectories,
recompute each ratio and report linear 2.5%/97.5% quantiles. Any invalid denominator draw
makes the interval unavailable; no draws are dropped. Fewer than two independent model
blocks yields no adjusted interval. Report raw and null intervals separately.

Offline `decode` consumes owned sparse emitted-activity features and labels.
It fits whole trials, scales from fit data only and tunes on validation data only.
The permutation null shuffles fit and validation labels separately.
Evaluation truth remains unchanged. The decoder never drives the task.

```bash
uv run pytest python/tests/test_analysis.py python/tests/test_calibration.py
```
