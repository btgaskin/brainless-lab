title: SORN
description: Inspect synchronous E/I dynamics and local online plasticity.
---

SORN implements synchronous binary excitatory/inhibitory dynamics,
E-to-E STDP, incoming-row normalisation and intrinsic threshold plasticity.
The historical `inhibitory_fraction` parameter denotes an I/E ratio.
Pruned E-to-E edges cannot regrow.

```bash
uv run pytest python/tests/test_sorn.py
```

Tests cover the declared equations, ordering, pruning, zero rows, reset,
frozen modes, ownership and batching. Software conformance does not establish
authors-code trajectory parity, criticality or biological fidelity.
