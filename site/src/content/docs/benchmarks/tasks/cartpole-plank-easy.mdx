description: Keep native surviving balance steps outcomes and their protocol explicit.
---

Plank CartPole Easy asks about surviving balance steps in one declared task.
Its native outcome retains surviving steps. The declared task bound is at most 15,000 steps; a shorter protocol must retain its actual bound. This is an opportunity bound, not an implemented oracle.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

The supplied example checks the active plan syntax. Select this task through its
`TaskSpec` and inspect its resolved ports, scoring window and seed policy before running.
Use `task_outcome` and retain the key, raw units and calibration status.

A signed null adjustment does not make this outcome comparable to another task's units.
Task performance does not establish general competence, learning or biological fidelity.
Historical benchmark protocols and tables retain their original evidence status.
