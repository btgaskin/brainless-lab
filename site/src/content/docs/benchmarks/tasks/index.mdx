Tracking, Pong, Plank CartPole Easy and delayed cue ask different questions.
They remain separate benchmark coordinates, even after a null adjustment.

- [Tracking](/benchmarks/tasks/tracking/) measures following a moving stimulus.
- [Pong](/benchmarks/tasks/pong/) measures paddle interception.
- [Plank CartPole Easy](/benchmarks/tasks/cartpole-plank-easy/) measures surviving steps.
- [Delayed cue](/benchmarks/tasks/delayed-cue/) measures a delayed binary response.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

Inspect the task's ports, action cadence and scored horizon.
Read its outcome key and raw units before interpreting an adjusted score.
Existing historical benchmark protocols retain their separate evidence status.
Continue with [calibration](/reference/analysis/).
