The active evaluation path compares named conditions within a task.
It retains native raw outcomes, matched independent-block contrasts and optional
task-matched null adjustments. It creates no cross-task competence score.

The four benchmark coordinates remain Tracking, Pong, Plank CartPole Easy and delayed
cue. Falandays and SORN are the active model families. Experimental capacity probes
extend the task opportunity without extending historical validation.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

Use the example to inspect the active plan syntax.
A development run does not satisfy a frozen historical confirmation protocol.
Existing Julia benchmark tables and accepted records retain their source and evidence state.

[capacity probes](/benchmarks/probes/) and [evidence](/handbook/experiments-evidence/).
