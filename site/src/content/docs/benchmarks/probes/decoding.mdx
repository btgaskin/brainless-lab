---
title: Offline probe decoding
description: Fit whole-trial diagnostics without leaking labels or events into evaluation.
---

A regularised linear diagnostic asks whether emitted activity contains recoverable
information about a declared binary label. It never controls the task and does not
replace the native outcome.

Use one fixed reservoir wiring per independent block, full trial resets and distinct
world seeds. The default split contains 256 fit, 128 validation and 256 evaluation
trials. Share those whole-trial subsets across cue_end, delay_end and response.
Coincident timestamps remain distinct observation points, rather than extra samples.

Fit feature centres and population standard deviations from fit trials only.
Replace a zero standard deviation with 1. Tune ridge regularisation on validation
accuracy over `[1e-4, 1e-2, 1, 100]`. Exact ties keep the smaller value.
Each observation point fits its own diagnostic.

The null separately shuffles fit and validation labels, then tunes by the same rule.
It never shuffles evaluation truth into training. Report diagnostic accuracy,
native accuracy on the same evaluation subset, constant prediction and permutation
accuracy separately. Preserve coefficients, scalers, split IDs and predictions.

```bash
uv run pytest python/tests/test_analysis.py
```

These tests exercise leakage, stable identities, missing/duplicate observations,
ownership, split-local permutation and solver storage bounds.
The six supported tasks exclude reversal adaptation and physical control.
A positive diagnostic result does not establish a task-controlled learning mechanism.
