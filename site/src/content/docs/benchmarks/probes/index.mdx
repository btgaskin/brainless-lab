The six additional families are recall interference, delayed XOR, evidence accumulation,
context integration, temporal order and reversal adaptation.
Together they retain 64 declared difficulty cells.

Delayed cue supplies the core binary recall coordinate.
A task score operationalises one response opportunity. It does not validate cognition,
a general capability or a biological interpretation.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

Use the active task options and resolved protocol.
Match the horizon to completed task episodes and keep diagnostic labels outside the
online controller. Physical control and reversal adaptation are excluded from the
binary offline decoder.

The [decoding guide](/benchmarks/probes/decoding/) describes six supported decoder tasks:
delayed cue, recall interference, delayed XOR, evidence accumulation, context integration
and temporal order. Historical stage-two studies retain their planned evidence state.
