This first benchmark describes the canonical Falandays node on the two core tasks. It does
not compare Falandays with another node and does not assign a cross-task rank.

## Protocol

Each task uses 20 independent blocks with one freshly constructed trial per block.

| Task | Horizon | Warm-up | Scored ticks | Root seed |
| --- | ---: | ---: | ---: | ---: |
| Tracking | 1,000 | 800 | 200 | 51,001 |
| Pong | 2,000 | 1,000 | 1,000 | 52,001 |

Both cases use full reset, trial-scoped construction, and mean aggregation. Each case has
one condition and no `baseline`. The task-declared anchors provide normalised context; they
are not comparator runs.

## Interpretation

Within this protocol, both tasks produced finite raw and normalised intervals across 20
blocks. These values describe this Falandays construction and these task settings.

The result does not establish general competence, superiority to another node, biological
fidelity, or stability outside the declared seeds and horizons. The evidence state is
exploratory.
