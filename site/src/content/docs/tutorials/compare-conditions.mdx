---
title: Compare conditions
description: Keep paired worlds, independent blocks and causal controls explicit.
---

A condition comparison asks whether declared mechanisms differ under a matched protocol.
The control must answer that question. Random action, blind input, shuffled input and
a plasticity freeze answer different questions.

Use named `EvaluationTarget` values in one `Plan`. Pair the declared world identity
across conditions. Keep distinct mechanism identities when the comparison requires
separate stochastic mechanisms. Stable identities make the schedule independent of
physical batch slots.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

Check the supplied syntax before authoring a comparison.
Use the public `ablate` or `benchmark` operation and explicit target identifiers;
do not introduce an operation-specific configuration schema.

Compare raw outcomes within a task and matched independent blocks.
Report raw paired contrasts separately from calibration and adjusted-score uncertainty.
Agents and ticks within one world are not extra independent samples.

`freeze_weights` disables weight adaptation while target or threshold adaptation
continues where the model supports it. `freeze_plasticity` freezes all declared
adaptation. Preserve the intervention tick in the scientific protocol.

Review [evaluation](/handbook/evaluation/), [calibration](/reference/analysis/)
and [evidence states](/handbook/experiments-evidence/).
