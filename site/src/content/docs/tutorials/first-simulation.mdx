---
title: Run your first simulation
description: Resolve a declared Python protocol and inspect a recorded task outcome.
---

A first run checks that a model, task and protocol can execute together.
It is an implementation diagnostic, not evidence of a learned capability.

## Install the locked environment

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then clone the repository:

```bash
git clone https://github.com/btgaskin/brainless-lab.git
cd brainless-lab
uv sync --locked
uv run brainlesslab check python/plans/delayed-cue.toml
```

The check command resolves the model, task, port widths, horizon and seed policy.
It does not advance a world. If it reports an incompatible protocol, correct the
declared configuration before running.

## Run and inspect

```bash
uv run brainlesslab run python/plans/delayed-cue.toml --root records
uv run brainlesslab inspect records/RECORD_ID
```

Replace `RECORD_ID` with the directory printed by the run command.
A record retains the request, resolved settings, realised random identities,
native outcomes, summaries and checksums. Inspect it before drawing a conclusion.

Read the outcome key, raw value, scoring window and calibration status together.
An unavailable calibration leaves the normalised value unavailable.
Do not treat a short diagnostic as a task's full evaluation protocol.

## Use the Python interface

The public package exports `NodeSpec`, `TaskSpec`, `CompositionSpec`,
`EvaluationSpec`, `EvaluationTarget`, `Plan`, `NumericalPolicy` and `ExecutionSpec`.
Use `simulate` for one diagnostic, or `resolve` and `execute` for a declared plan.
`task_outcome` returns the task-declared outcome rather than an arbitrary diagnostic.

For a small in-memory plan, construct the same layers directly:

```python
from brainlesslab import (
    CompositionSpec, EvaluationSpec, EvaluationTarget, NodeSpec, Plan, TaskSpec, resolve,
)

composition = CompositionSpec(
    node=NodeSpec("sorn"), task=TaskSpec("delayed_cue"), count=32,
)
plan = Plan(
    "first-cue", (EvaluationTarget("sorn-cue", composition),),
    evaluation=EvaluationSpec(blocks=2, trials_per_block=2, root_seed=26),
)
resolved = resolve(plan)
print(resolved)
```

This resolves without executing. Inspect its task horizon and ports before calling
`execute` with a declared `ExecutionSpec`.

Scientific settings belong to the composition and evaluation. Backend, batch size,
memory and recording belong to `ExecutionSpec`. The default CPU policy is float64.
Metal requires explicit float32 numerics and a separate qualification.
