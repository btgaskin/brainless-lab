title: Run your first simulation
description: Install BrainlessLab, run one Falandays agent on Tracking, and read the declared task outcome.
---

This tutorial runs one diagnostic simulation. It does not create a research record or an
uncertainty estimate.

## Install the repository

BrainlessLab requires Julia 1.10 or later.

```bash
git clone https://github.com/btgaskin/brainless-lab.git
cd brainless-lab
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

## Run Tracking

```bash
julia --project=. -e '
using BrainlessLab
sim = simulate(:tracking; node=:falandays, ticks=300, seed=11)
println(task_outcome(sim))
'
```

`simulate` creates a Falandays reservoir, couples it to the Tracking task, and runs one
closed loop. It returns a `SimResult` in memory.

## Check the result

`task_outcome(sim)` identifies the task's declared outcome. A scored result contains:

- `key`, the task outcome name;
- `raw`, the task-native value;
- `normalized`, the value relative to that task's declared anchors.

The command succeeds when Julia prints an outcome without an exception. One run can reveal
a setup problem or an interesting trajectory. It cannot establish typical performance.

Next, [create a reproducible profile](/tutorials/reproducible-profile/) when you need
repeated trials and a portable record.
