## Python and Quadrants

The active implementation lives under `python/src/brainlesslab/`. Python constructs
models and analyses results; Quadrants advances neural and task state in bounded batches.
Start with [your first simulation](/tutorials/first-simulation/) and read
[platform limits](/platform-limits/) for supported scope.

Python equation conformance, historical fixture parity, backend qualification and
observed task performance are separate evidence. Rewriting the software does not
rerun or promote a study.

## Earlier Julia implementation

The pre-rewrite Julia source is preserved at
[Git revision d0fc756d](https://github.com/btgaskin/brainless-lab/tree/d0fc756d).
Its Falandays validation covers declared reference trajectories at that implementation
boundary. It does not automatically qualify Python equations, arbitrary seeds,
backends, task performance or biological interpretations.

Use the archived source for its interfaces, commands, registries, evolution and body
composition. These capabilities do not describe the active Python API.

The local archive tag is `julia-v0.3-final`. To inspect and test that version in a
separate checkout:

```bash
git worktree add ../brainlesslab-history d0fc756d4efe23abbad79314574beb0d3500de61
cd ../brainlesslab-history
julia --project=. -e 'using Pkg; Pkg.instantiate(); Pkg.test()'
```
