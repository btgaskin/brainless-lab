The registered `:sorn` node separates binary excitatory and inhibitory populations. Its
excitatory recurrent weights use spike-timing-dependent plasticity and incoming synaptic
normalisation. Intrinsic plasticity adapts each excitatory threshold towards a target
activity.

The standard runtime can construct, step, replay, and freeze the node. The current tests do
not establish paper-level prediction performance, biological plausibility, or
avalanche-scaling criticality. No accepted benchmark record qualifies SORN as a reference
node.

SORN is a stable Julia registry node with its own software-conformance boundary. The
landing-page browser port is an illustrative comparison in Pong, Tracking, and CartPole
Easy. Its display parameters and seeds differ from the fixed 200-node benchmark profile.
Browser replay tests do not establish numerical parity with Julia or benchmark performance.

Choose SORN in the landing demo, select a task, and use reset to reconstruct the same
display world. Read the [benchmark profile](/benchmarks/models/sorn/) for the research
assembly and its separate evidence boundary.
