description: Binary excitatory and inhibitory dynamics with online STDP, intrinsic threshold plasticity, and synaptic normalisation.

The registered `:sorn` node separates binary excitatory and inhibitory populations. Its
excitatory recurrent weights use spike-timing-dependent plasticity and incoming synaptic
normalisation. Intrinsic plasticity adapts each excitatory threshold towards a target
activity.

The standard runtime can construct, step, replay, and freeze the node. The current tests do
not establish paper-level prediction performance, biological plausibility, or
avalanche-scaling criticality. No accepted benchmark record qualifies SORN as a reference
node.

SORN is an archived registry node with its own software-conformance boundary. The
landing-page browser port was an illustrative comparison in Pong, Tracking and CartPole.
Its display parameters and seeds differ from the fixed 200-node benchmark profile.
Browser replay tests do not establish numerical parity with the archived implementation or benchmark performance.

The earlier browser interface is retained in the
[archived feature page](https://github.com/btgaskin/brainless-lab/blob/d0fc756d/site/src/content/docs/experimental/features/sorn-node.mdx).
It is not the current landing-page interface. Read the active
[SORN guide](/benchmarks/models/sorn/) or [version history](/legacy/) for the relevant boundary.
