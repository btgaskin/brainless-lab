The registered `:sorn` node separates binary excitatory and inhibitory populations. Its
excitatory recurrent weights use spike-timing-dependent plasticity and incoming synaptic
normalisation. Intrinsic plasticity adapts each excitatory threshold towards a target
activity.

The standard runtime can construct, step, replay, and freeze the node. The current tests do
not establish paper-level prediction performance, biological plausibility, or
avalanche-scaling criticality. No accepted benchmark record qualifies SORN as a reference
node.
