The `:delayed_cue` task tests whether controller state retains a binary cue through a blank
interval. Only response-period actions contribute to the decision. Persistent and hidden
cue modes support controls with identical seeded worlds.

The software is integrated into the four-task v2 benchmark. Its initial model results are
development observations near chance; confirmation remains pending. Read the
[task guide](/benchmarks/tasks/delayed-cue/) for a runnable example, outcome definition,
controls, and interpretation limits.
