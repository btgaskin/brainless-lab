The `word_sequence_2021` task presents a probabilistic grammar through five lexical channels.
Partial-sentence probes follow the complete training sequence in the same trial. It declares
no scalar task objective. Response rasters, pre-update target errors and completion
correlations are diagnostics.

The [archived programme](https://github.com/btgaskin/brainless-lab/tree/d0fc756d/experiments/initialisation-adaptation/programme)
retains its execution instructions, source commit, parameters, budgets and differences
from the source notebook. The equation check compares explicit initial states; it does not
establish full notebook parity or reproduce a paper's numerical results.

Read the [archived feature instructions](https://github.com/btgaskin/brainless-lab/blob/d0fc756d/site/src/content/docs/experimental/features/word-sequence.mdx)
for branch execution and offline reports. See [version history](/legacy/) for the implementation boundary.
