Six probe families extend coverage beyond closed sensorimotor control. Native responses
define performance. An optional decoder measures recoverable task information separately,
using whole-trial splits within independent wiring blocks.

The [capacity-probe guide](/benchmarks/probes/) lists controls, 64 difficulty presets and
membership status. Software is integrated; model comparisons, confirmation and selective
core admission remain pending. The existing benchmark v2 is unchanged.
