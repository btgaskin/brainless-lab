The active Python release contains Falandays, SORN, the declared physical tasks,
delayed cue and six additional capacity-probe families. Their preset library has
64 cells in total, including delayed cue.
Probe availability describes software readiness, not validated learning or cognition.

```bash
uv run brainlesslab check python/plans/delayed-cue.toml
```

The resolved example checks an active composition without executing a world.
Read [the catalogue](/reference/core-catalog/) and [platform limits](/platform-limits/)
before choosing another task.

General body composition, heterogeneous populations, arbitrary node registries,
evolution, general autodiff and checkpoint/resume remain historical or unimplemented
in this release. Earlier feature pages are marked historical; see
[version history](/legacy/). Their availability does not describe the Python successor.

Accepted research and archived protocols retain their original source and status.
Continue with [research records](/research/catalogue/) and
[implementation exercises](/python/learning/).
