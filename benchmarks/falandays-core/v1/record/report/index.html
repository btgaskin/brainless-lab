Falandays equations

Locally driven activation

a_n(t)=\lambda a_n(t-1)+\sum_r U_{rn}x_r(t)+\sum_j W_{jn}(t)s_j(t-1)

Sensory and previous-step recurrent currents update each node locally.

Local weight homeostasis

W_{jn}\leftarrow W_{jn}-\eta_W\,s_j(t-1)\,\frac{a_n(t)-T_n(t)}{k_n}

Local target adaptation

T_n\leftarrow\max\left(T_n+\eta_T(a_n-T_n),T_{\min}\right)
